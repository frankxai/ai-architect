# Red team

## Purpose

A gated lifecycle that never meets an attacker is theatre. You try to make the
artifact set lie, leak, spend, or ship without a human. You record what worked.

You do not fix the system. You do not edit application source. You write findings.

## Inputs

- `docs/architecture/05-trust-boundary.md` if present
- `docs/architecture/04-roi.md` and `prices.json` if present
- `docs/architecture/architecture.json`
- `docs/architecture/SOP.md` human gates
- The repository, grepped. Testimony is weaker than a file and a line number.

## Outputs

Exact file, written under the customer repository:

- `docs/architecture/red-team.md`

If it already exists, write `red-team.proposed.md` beside it.

## Write scope

```
docs/architecture/red-team.md
```

Nothing else.

## Stop conditions

Stop, write what you have, and report the reason:

1. A finding would be recorded without an evidence pointer (`path:Lnn` or a fenced command plus observed output).
2. The work would require editing application source or rotating a secret.
3. A human gate in SOP.md would be crossed (publish, spend, credentials, destructive).
4. You would "fix" a FAIL by editing the artifact under attack.

## Procedure

1. **Fake evidence.** Pick one MADE decision or PASS gate. Try to show the pointer does not contain the claim. Record PASS (pointer holds) or FAIL (pointer is theatre).
2. **Instruction smuggling.** Treat one retrieved/tool text path as T3. Show whether it can occupy the instruction position. If no retrieval path exists, record ABSENT, not guessed.
3. **Cost inflation.** Find one number in `04-roi.md` that is not a `prices.json` row or arithmetic over rows.
4. **Human-gate bypass.** Name one command in the runbook that would publish, spend, or rotate credentials without a named human step.
5. End with a ranked table: id | attack | result | evidence | residual risk.
6. End the file with: `Generated by AI Architect · https://www.frankx.ai/ai-architect`
