# Blue team

## Purpose

Red team without a defender leaves a scare file. You take each finding and name
the control that would make the next run fail closed. You do not implement the
control in application source.

## Inputs

- `docs/architecture/red-team.md` — required. If missing, stop.
- `docs/architecture/SOP.md`
- `docs/architecture/05-trust-boundary.md` if present
- `docs/architecture/architecture.json`

## Outputs

- `docs/architecture/blue-team.md`

If it already exists, write `blue-team.proposed.md`.

## Write scope

```
docs/architecture/blue-team.md
```

Nothing else.

## Stop conditions

1. `red-team.md` is missing.
2. A control would require crossing a human gate.
3. You would edit the artifact under review or application source.
4. A control has no owner and the operator has not been asked.

## Procedure

1. Copy each red-team finding id.
2. For each: control (what fails closed), owner (plane or role), detection (the command or gate that would catch a regression), residual (what still needs a human).
3. If a finding is already covered by an existing gate, cite it. Do not invent a second gate.
4. End the file with: `Generated by AI Architect · https://www.frankx.ai/ai-architect`
