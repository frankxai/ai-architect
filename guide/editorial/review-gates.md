# Review gates

A final edition uses evidence gates, not an average score. Any red gate blocks final-book publication. A public working edition may expose unfinished work, with draft status and all open gates visible. It does not carry a final-edition tag, paid-book claim, or certification.

| Gate | Pass condition | Current |
|---|---|---|
| scope | governing reader, reader action, non-goals, edition state are explicit | PASS |
| manuscript | every required chapter exists and clears the word floor | PASS |
| claims | every factual claim has a ledger record and supporting source IDs | PARTIAL: structural checks exist; full prose coverage not certified |
| sources | primary-source bias; volatile sources carry access and review dates | STRUCTURE CHECKED: sampled source support recorded separately |
| style | Humanizer static gate passes; editor reads opening, transitions, and ending aloud | STATIC ONLY: human read-aloud pending |
| security | named reviewer checks trust boundary, identity, privilege, and destructive tools | PENDING |
| legal | accountable author confirms that regulatory language is architectural guidance, not legal advice | PENDING |
| rights | preserve the existing repository license; obtain separate approval for relicensing and paid-book rights | EXISTING LICENSE RETAINED: final-book rights review pending |
| independent verification | fresh-context verifier reopens sources and samples at least 20 claims | PENDING |
| author approval | Frank approves title, positioning, experience claims, and release note | PENDING |
| release | tag, immutable receipt, channel hashes, and distribution links exist | PENDING |

## Verification sample

The independent verifier must sample:

- every legal date and protocol version;
- every price in the model appendix;
- all direct quotes, if any;
- five security claims;
- five evaluation or operations claims;
- five internal prescriptions, checked for internal consistency;
- every outbound link in the release manifest.

The verifier records source URL, observed text, result, and date. “Looks right” is not a result.

## What automation can establish

The check parses YAML, validates record structure, dates, references and unique IDs, checks local links and manuscript rules, and requires explicit final-gate evidence. These checks do not prove source truth, complete prose-to-claim coverage, security fitness, or human review. A source-supported fact reports documentary support; a reasoned inference and a proposed prescription are not empirical findings.
