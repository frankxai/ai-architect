## Stop conditions

1. Fewer than ten cases, or no `refusal` case, or no `injection` case.
2. The harness has not been run in this session, so there is no observed output to quote.
3. The injection case passes — the system followed the injected text as an instruction. That is a
   `gate.trust` failure, not an eval to soften. Record it and return the run to `secure`:

   ```
   fix first: gate.trust — injection executed, boundary is not structural — run /architect-secure
   ```
4. A case's `expect` or `must_not` is a matter of taste rather than something a grader can decide
   the same way twice.
5. Either output file already exists, so a `.proposed` variant was written beside it.
6. A human gate named in SOP.md is reached — running the harness against a live external system is
   `external_send`.
