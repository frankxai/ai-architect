# ADR-0008: Block Deployment on Deterministic Contract and Adversarial Eval Suites

- **Status:** Accepted
- **Date:** 2026-10-24
- **Pattern:** PAT-08
- **Mitigates:** FM-08

## Context
Prompt or skill edits can silently break refusal boundaries or output schemas while passing casual manual checks.

## Decision
Require every pull request to pass a deterministic evaluation triad covering golden capability cases, refusal boundaries, and prompt-injection probes.

## Alternatives Considered and Rejected
1. **Rejected option 1:** Manual spot-checking without versioned JSONL regression cases.
2. **Rejected option 2:** shipping skills without eval suites.

## Consequences
- **Positive:** Deterministically prevents `FM-08` and produces a machine-checkable audit trail.
- **Negative / Cost:** Adds explicit schema and gate checks to the build pipeline.
