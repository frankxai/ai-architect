# ADR-0010: Enforce Release-Gate Receipts and 48-Hour Provider Exit Drills

- **Status:** Accepted
- **Date:** 2026-10-24
- **Pattern:** PAT-10
- **Mitigates:** FM-10

## Context
Shipping digital products or agent workflows without clean-room buyer simulation leads to broken archives and vendor lock-in.

## Decision
Gate every release on G0-G5 receipts (including extracting the built archive in /tmp outside git and running verification cold) and maintain a documented 48-hour provider exit drill.

## Alternatives Considered and Rejected
1. **Rejected option 1:** Running tests only inside the developer git checkout.
2. **Rejected option 2:** opening live checkout before G0-G5 pass.

## Consequences
- **Positive:** Deterministically prevents `FM-10` and produces a machine-checkable audit trail.
- **Negative / Cost:** Adds explicit schema and gate checks to the build pipeline.
