# ADR-0005: Harden Remote and Local MCP Servers Against Confused-Deputy Calls

- **Status:** Accepted
- **Date:** 2026-10-24
- **Pattern:** PAT-05
- **Mitigates:** FM-05

## Context
MCP tool descriptions and arguments can carry prompt-injection payloads or path-traversal sequences.

## Decision
Wrap MCP tool descriptions and results as untrusted data, validate inputs against closed JSON schemas, require idempotency keys on writes, and enforce realpath directory containment.

## Alternatives Considered and Rejected
1. **Rejected option 1:** Trusting MCP tool descriptions as system instructions.
2. **Rejected option 2:** string-prefix path checks vulnerable to ../ traversal.

## Consequences
- **Positive:** Deterministically prevents `FM-05` and produces a machine-checkable audit trail.
- **Negative / Cost:** Adds explicit schema and gate checks to the build pipeline.
