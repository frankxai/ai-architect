# ADR-0004: Choose Code-Led Orchestration Over Open-Ended Autonomous Swarms

- **Status:** Accepted
- **Date:** 2026-10-24
- **Pattern:** PAT-04
- **Mitigates:** FM-04

## Context
Unconstrained peer-to-peer multi-agent loops multiply token spend, clobber shared files, and rubber-stamp their own bugs.

## Decision
Drive multi-agent work from a deterministic TypeScript supervisor that enforces disjoint writePaths per wave, caps recursion depth at 1, and requires a read-only Checker from a different model family.

## Alternatives Considered and Rejected
1. **Rejected option 1:** Open-ended chat loops between agents.
2. **Rejected option 2:** same-model self-review in the authoring thread.

## Consequences
- **Positive:** Deterministically prevents `FM-04` and produces a machine-checkable audit trail.
- **Negative / Cost:** Adds explicit schema and gate checks to the build pipeline.
