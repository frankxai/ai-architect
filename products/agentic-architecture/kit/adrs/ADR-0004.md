# ADR-0004: Choose code-led orchestration over open-ended autonomous swarms

- **Status:** Accepted
- **Date:** 2026-10-24
- **Pattern:** PAT-04
- **Mitigates:** FM-04

## Context
Multi-agent workflows need parallel specialist throughput and independent verification, but open-ended agent chat loops multiply token cost by ~15x (`S21`), clobber shared files, and self-approve defects.

## Decision
Use a deterministic TypeScript supervisor (`kit/workflows/supervisor-maker-checker.ts`) that dispatches specialists with typed handoff packets, enforces disjoint `writePaths` per wave (`E_WRITE_COLLISION`), forbids child subagent spawning (`E_RECURSION_DEPTH_EXCEEDED` / `E_SUBAGENT_SPAWN_FORBIDDEN`), and requires a read-only Checker on a distinct model provider family (`E_CHECKER_ISOLATION`).

## Alternatives considered and rejected
1. **Autonomous peer-to-peer group chat where agents converse until reaching consensus:** Rejected because token consumption scales superlinearly with turn count and peer count while early framing errors propagate unchecked.
2. **Same-model self-critique in the authoring conversation thread:** Rejected because the reviewer shares the maker's provider priors and context biases, missing systematic defects.
3. **Concurrent specialist workers sharing a mutable git branch without file-path locks:** Rejected because parallel writes to lockfiles or shared manifests silently overwrite sibling commits.

## Consequences
- **Positive:** Prevents parallel file clobbering (`E_WRITE_COLLISION`), unbounded subagent fanout (`E_RECURSION_DEPTH_EXCEEDED`), and same-family self-grading (`E_CHECKER_ISOLATION`).
- **Negative:** Requires provisioning API credentials for at least two model provider families and serializing typed `HandoffPacket` objects at every wave boundary.
- **Neutral:** Replaces open-ended multi-agent chat rooms with a deterministic supervisor state machine (`kit/workflows/supervisor-maker-checker.ts`).
