# ADR-0001: Separate read-only context retrieval from consequential tool writes

- **Status:** Accepted
- **Date:** 2026-10-24
- **Pattern:** PAT-01
- **Mitigates:** FM-01

## Context
Agents ingesting untrusted text from support tickets, web pages, or webhooks can be steered by indirect prompt injection into invoking state-mutating tools.

## Decision
Route all tool calls through a Scoped Capability Proxy (`kit/mcp/reference-mcp-server.mjs`) that requires OAuth 2.1 RFC 8707 audience-bound bearer tokens, wraps Tier 0 reads in `<untrusted-content>`, enforces `docs/architecture/` path containment and `idempotencyKey` on Tier 1 drafts, and requires an HMAC-SHA256 `approvalToken` bound to `(tenantId, toolName, proposerSub, approverSub, expiresAt, canonicalParams)` from a distinct authenticated principal on Tier 2 writes.

## Alternatives considered and rejected
1. **System-prompt instruction only ('Never run destructive tools without asking'):** Rejected because instructions embedded in retrieved customer tickets or web pages share the same token stream and routinely override system-prompt prose.
2. **Single static API key mounted in the agent container environment:** Rejected because any code-execution or shell tool can read `process.env` and call downstream endpoints directly, bypassing tool-schema restrictions.
3. **Human confirmation prompt on every Tier 0 read and search call:** Rejected because prompting operators 30 times per run causes confirmation fatigue, training reviewers to approve requests without inspecting parameters.

## Consequences
- **Positive:** Prevents unattended external writes and self-approval (`E_SELF_APPROVAL_FORBIDDEN`) by binding Phase 2 execution to a server-stored `proposalId` and distinct authenticated approver.
- **Negative:** Adds one synchronous human or secondary-principal round-trip for every Tier 2/3 action and requires maintaining a short-lived proposal store.
- **Neutral:** Moves tool authorization out of prompt instructions and into the MCP capability proxy (`kit/mcp/reference-mcp-server.mjs`).
