# ADR-0001: Separate Read-Only Context Retrieval from Consequential Tool Writes

- **Status:** Accepted
- **Date:** 2026-10-24
- **Pattern:** PAT-01
- **Mitigates:** FM-01

## Context
Agents ingesting untrusted text from tickets, web pages, or webhooks can be tricked by indirect prompt injection into calling state-changing tools.

## Decision
Enforce a Scoped Capability Proxy that separates Tier 0 read-only tools, Tier 1 idempotent draft tools, and Tier 2 outward writes requiring a two-phase approval token signed by a distinct principal.

## Alternatives Considered and Rejected
1. **Rejected option 1:** System-prompt warnings alone (bypassed by injection).
2. **Rejected option 2:** single shared container API key (allows arbitrary calls).

## Consequences
- **Positive:** Deterministically prevents `FM-01` and produces a machine-checkable audit trail.
- **Negative / Cost:** Adds explicit schema and gate checks to the build pipeline.
