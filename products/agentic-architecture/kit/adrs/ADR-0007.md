# ADR-0007: Bound Token, Retry, and Human-Review Cost per Accepted Outcome

- **Status:** Accepted
- **Date:** 2026-10-24
- **Pattern:** PAT-07
- **Mitigates:** FM-07

## Context
Context compaction drops operational constraints, and retry loops on large contexts silently blow through run budgets.

## Decision
Keep standing constraints in a verbatim working document outside compacted chat history, and enforce an all-attempts cost circuit breaker (70% soft warning, 80% hard stop, maxRetries=2).

## Alternatives Considered and Rejected
1. **Rejected option 1:** Relying on lossy chat summarization for constraints.
2. **Rejected option 2:** calculating unit economics from first-pass happy-path tokens only.

## Consequences
- **Positive:** Deterministically prevents `FM-07` and produces a machine-checkable audit trail.
- **Negative / Cost:** Adds explicit schema and gate checks to the build pipeline.
