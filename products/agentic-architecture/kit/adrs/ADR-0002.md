# ADR-0002: Isolate Vendor SDKs Behind One Canonical Capability Seam

- **Status:** Accepted
- **Date:** 2026-10-24
- **Pattern:** PAT-02
- **Mitigates:** FM-02

## Context
Model providers frequently deprecate aliases and alter structured-output behavior without notice.

## Decision
Route all model invocations through a task-tiered gateway using pinned snapshot IDs, strict JSON schema validation, and a tested secondary provider family.

## Alternatives Considered and Rejected
1. **Rejected option 1:** Hardcoding floating vendor aliases across application files.
2. **Rejected option 2:** coupling business logic to one vendor's proprietary SDK types.

## Consequences
- **Positive:** Deterministically prevents `FM-02` and produces a machine-checkable audit trail.
- **Negative / Cost:** Adds explicit schema and gate checks to the build pipeline.
