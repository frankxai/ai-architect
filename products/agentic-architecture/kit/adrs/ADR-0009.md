# ADR-0009: Record Reconstructable Run Receipts Without Leaking Customer Secrets

- **Status:** Accepted
- **Date:** 2026-10-24
- **Pattern:** PAT-09
- **Mitigates:** FM-09

## Context
Production failures are impossible to debug without span traces, but raw payload logging leaks secrets and customer PII.

## Decision
Emit OpenTelemetry GenAI spans through a deterministic redaction filter that strips secrets and email addresses, paired with sanitized replay fixtures.

## Alternatives Considered and Rejected
1. **Rejected option 1:** Dumping raw request headers or buyer emails to stdout/stderr.
2. **Rejected option 2:** running with zero structured telemetry.

## Consequences
- **Positive:** Deterministically prevents `FM-09` and produces a machine-checkable audit trail.
- **Negative / Cost:** Adds explicit schema and gate checks to the build pipeline.
