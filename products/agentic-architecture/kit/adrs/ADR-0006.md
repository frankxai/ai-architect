# ADR-0006: Design Idempotent Saga Transitions for Long-Running Agent Jobs

- **Status:** Accepted
- **Date:** 2026-10-24
- **Pattern:** PAT-06
- **Mitigates:** FM-06

## Context
Mid-write crashes and out-of-order webhook deliveries (such as a refund arriving before payment) corrupt entitlement state.

## Decision
Write convergent state before marking an event ID processed (write-before-mark) and record a refunded tombstone when cancellation arrives first so late payment events cannot grant access.

## Alternatives Considered and Rejected
1. **Rejected option 1:** Marking event IDs processed before database writes succeed.
2. **Rejected option 2:** returning 422 on early refunds.

## Consequences
- **Positive:** Deterministically prevents `FM-06` and produces a machine-checkable audit trail.
- **Negative / Cost:** Adds explicit schema and gate checks to the build pipeline.
